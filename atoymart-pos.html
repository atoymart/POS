Backup ke Google Sheets

Backup dilakukan lewat Google Apps Script Web App milik akun Google Anda sendiri (gratis). Ikuti langkah setup satu kali di bawah, lalu tempel URL-nya di sini.

Cara Setup Google Sheets (sekali saja)

  1. Buat Google Sheet baru, beri nama misalnya Atoymart Data.
  2. Buka menu Extensions → Apps Script.
  3. Hapus kode default, lalu tempel kode di bawah ini.
  4. Klik Deploy → New deployment, pilih tipe Web app.
  5. Execute as: Me. Who has access: Anyone. Klik Deploy dan izinkan akses.
  6. Salin URL Web App yang muncul (diakhiri /exec) dan tempel di kolom "Web App URL" di atas.

Data & Cadangan Lokal

Semua data tersimpan di browser ini (localStorage). Disarankan backup rutin ke Google Sheets agar aman jika browser/komputer bermasalah.
